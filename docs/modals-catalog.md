# Modal Catalog

Каталог всех глобальных модалок проекта. Общая архитектура, слои и правила
добавления описаны в [modals.md](./modals.md). Этот файл — быстрый реестр:
ключ, слой, stacking, назначение, триггер и действия.

## Легенда

- `layer`: `global` (продуктовый UI) | `system` (ошибки/блокеры; сейчас таких
  модалок нет, слой оставлен в реестре);
- `stacking`: `base` (самостоятельная модалка) | `stacked` (поверх текущей base);
- `priority`: при нескольких открытых `base` видна одна — меньший priority,
  при равенстве — открытая последней. `1` — near-miss над живой доской, `2` —
  карточка уровня и результат партии;
- `route-bound`: закрывается при смене маршрута (`closeOnRouteChange`).

Все модалки открываются одним общим API стора: `useShowModal()` /
`useHideModal()` / `useHideModals()` с ключом из `MODAL_KEYS` — отдельных
`showModalX`/`hideModalX` нет.

## Список модалок

| Ключ         | Layer  | Stacking | Priority | Route-bound | Назначение                                        | Триггер                                                        | Действия                |
| ------------ | ------ | -------- | -------- | ----------- | ------------------------------------------------- | -------------------------------------------------------------- | ----------------------- |
| `levelStart` | global | base     | 2        | да          | Карточка уровня: цели, ходы, предбустеры          | «Играть» на главной, тап по уровню карты, «Дальше» / «Ещё раз» | «Играть»                |
| `outOfMoves` | global | base     | 1        | да          | Near-miss «Ещё чуть-чуть!»: +5 ходов              | `onOutOfMoves(offer)` у хоста партии, первый раз за партию     | «+5 ходов», «Сдаться»   |
| `victory`    | global | base     | 2        | да          | Карточка победы со звёздами (Figma `16448-14184`) | `onFinish({ isVictory: true, ... })` у хоста партии            | «Дальше», «На главную»  |
| `defeat`     | global | base     | 2        | да          | Карточка поражения (Figma `16448-13976`)          | `onFinish({ isVictory: false, ... })` у хоста партии           | «Ещё раз», «На главную» |

Модалок ошибки и подтверждения выхода нет: отказ рантайма хост показывает на
главной (`onError`), выход из партии идёт без подтверждения (`onExitRequest`).

## Детали

### levelStart

- Props: `ILevelStartModalProps` — `{ levelNumber, name?, moves, goals,
preBoosterOptions, bestStars?, onStart, onClose }`. Номер и название уровня,
  цели кружками
  (`ui/common/GoalChips`), лучший результат звёздами (`ui/common/ResultStars`)
  и выбор предуровневых бустеров (ракета, бомба, радуга - живёт в карточке до
  «Играть»). Пустой `preBoosterOptions` прячет выбор (первый уровень). Иконки
  и подписи целей и бустеров - из описания элементов в скине
  (`getElementIcon`/`getElementLabel`, [skin.md](./skin.md)).
- «Играть» закрывает карточку и зовёт `onStart(выбранные)`; крестик и Escape -
  `onClose` (с главной и карты карточка просто закрывается, над фоном прошлой
  партии хост уходит на главную).
- View: `src/widgets/modals/ui/levelStart`.

### outOfMoves

- Props: `IOutOfMovesModalProps` — `{ goalsLeft, extraMoves, onContinue,
onGiveUp }`. Ходы кончились, цели нет: карточка «Ещё чуть-чуть!» показывает
  незакрытые цели (`GoalChips`) и предлагает добавочные ходы. Доска под ней
  стоит (`paused` у хоста + ожидание решения в рантайме).
- Escape и «Сдаться» - `onGiveUp` (поражение), клик мимо карточки её не
  закрывает. `priority: 1` - важнее карточек результата: исхода ещё нет.
- View: `src/widgets/modals/ui/outOfMoves`.

### victory

- Props: `IGameResultModalProps` — `{ onPlay, onHome, score, stars }`. Что
  делают кнопки, решает хост партии (`pages/main/model/useMainFlowStore`),
  карточка только закрывается и зовёт обработчик; звёзды и очки она рисует
  под артом (`ResultStars`).
- Открывается поверх фона партии: доски под карточкой уже нет (рантайм
  партии уничтожен по исходу: `finish` снимает `party`, экран размонтируется). Сам экран партии — не модалка, а режим главной `/`,
  поэтому базы под результатом нет и он объявлен `base` с `priority: 2`
  (см. [game-flow.md](./game-flow.md)). Дизайн по Figma `16448-14184`: тёмная
  карта (`surface="dark"`), арт, звёзды и очки (у уровня без звёзд,
  `stars: null`, - только очки), заголовок «Победа!», короткий
  текст, две кнопки. Наград нет; арт (`gameVictoryArtUrl`) остаётся
  плейсхолдером.
- Действия — общие для победы и поражения: чистое `resolveGameResultActions`
  (победа — «Дальше»/«На главную», поражение — «Ещё раз»/«На главную») плюс
  `useGameResultActions`. Крестика в углу нет и клик мимо карточки её не
  закрывает (`closeOnOverlayClick={false}`) — выбор одного из двух действий
  обязателен; Escape ведёт туда же, куда «На главную».
- View: `src/widgets/modals/ui/victory`.

### defeat

- Props: `IGameResultModalProps`, как у `victory` (звёзд у поражения нет).
- Открывается поверх фона партии (`base`, `priority: 2` — как `victory`).
  Дизайн по Figma `16448-13976`: тёмная карта (`surface="dark"`), заголовок
  «Ходы закончились», описание, без арта и призов.
- Действия — общие для победы и поражения (`useGameResultActions`), без
  крестика в углу — как у `victory`.
- View: `src/widgets/modals/ui/defeat`.

## Как добавить новую модалку

Порядок шагов — в [modals.md — How To Add A Modal](./modals.md). После
добавления заведи строку в таблицу выше и обнови `docs/CODEMAP.md`, если
изменился набор entrypoints.
