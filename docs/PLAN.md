# План: match3-pixi

Статус и журнал фаз - [в конце файла](#журнал-фаз).

`match3-pixi` - Match-3 шаблон на Pixi с тем же функционалом, что у
Phaser-шаблона `match3-template`, из которого он перенесён. Перенос делался,
пока папка лежала внутри репозитория Phaser-шаблона; дальше она живёт
**отдельным git-репозиторием**. Отсюда главное правило: папка самодостаточна.
Перенос завершён (фазы 0-6, [журнал](#журнал-фаз)); этот файл - история
переноса, инварианты проекта и список отклонений от исходника.

## Инварианты

1. **Независимость.** Внутри папки - всё, что нужно проекту: `package.json` и
   `package-lock.json`, конфиги Vite/TypeScript/ESLint/Prettier/Vitest/PostCSS,
   `index.html`, `public/`, `src/`, `config/`, `scripts/`, `.env.example`,
   `.gitignore`, `.prettierignore`, `.editorconfig`, `.husky/`, `.gitlab-ci.yml`,
   `Dockerfile`/`nginx.conf`/`docker-compose.yaml`, `README.md`, `CLAUDE.md`,
   `AGENTS.md`, `docs/`. Ни одного импорта, пути или скрипта, который
   смотрит наружу (`../src`, корневые конфиги, корневые `node_modules`).
   Проверка: скопировать папку в пустой каталог вне репозитория,
   `npm ci && npm run build && npm run test:ci` - зелёное.
2. **Функционал один в один** с Phaser-шаблоном: главная («Играть · уровень N»,
   «Уровни», «Витрина», «Редактор»), карта уровней, витрина, карточки
   `levelStart`/`outOfMoves`/`victory`/`defeat`, пак `main` (30 уровней) и
   уровни витрины, редактор паков с превью и бот-проверкой, экспорт/импорт
   пака, `levels:report`/`levels:import`, прогресс, бустеры и предуровневые
   бустеры, подсказки механик, звук, перф-гейт, QA-флаги (`?level`, `?seed`,
   `?perf`, `?insets`, `?gameDebug`), флаг сборки `VITE_ENABLE_EDITOR`,
   вёрстка и модалки, тексты. Движок тот же, поэтому при одинаковом зерне
   партия даёт те же шаги, каскады, события `onBoardEvent` и исход.
3. **Стек тот же**: Vite + React 19 + TypeScript strict, React Router, Zustand,
   SCSS Modules, Vitest + RTL, `motion` для DOM-анимаций. Phaser заменён на
   **Pixi v8** (`pixi.js`), твины рантайма - **GSAP 3** (`gsap`), Spine -
   `@esotericsoftware/spine-pixi-v8`. Версии зависимостей фиксируются в
   `package.json` при установке; Phaser в проекте отсутствует полностью.
4. **Ключи `localStorage`** - свой префикс `STORAGE_PREFIX = 'match3-pixi'`
   (`match3-pixi:progress:v1`, `match3-pixi:progress:<packId>:v1`,
   `match3-pixi:sound-muted`, `match3-pixi:editor-workspace:v1`,
   `match3-pixi:editor-columns:v1`). Проект новый, поэтому
   `LEGACY_STORAGE_KEYS` и `migrateStorageKey` не переносятся, перенос
   черновика старого одиночного редактора (`draft`) - тоже.
5. **Ассеты те же**, что у скина `default` Phaser-шаблона (кадры фишек,
   спецфишек, блокеров, иконки, шрифты). Оговорка про права на арт из README
   Phaser-шаблона переносится как есть: до выпуска кадры подтвердить по правам
   или заменить. Исходные атласы (`assets-for-new-match3/`) не копируются.
6. **Требования заказчика**, которых нет в Phaser-шаблоне:
   - **WebGPU**: `autoDetectRenderer`/`Application.init` с
     `preference: 'webgpu'` и откатом на WebGL; QA-флаг `?renderer=webgl|webgpu`
     для принудительного выбора. Все эффекты проверяются на обоих.
   - **Spine**: поддержка в рантайме и скине (вид клетки `spine` в
     `TSkinCellView`, фабрика в `CELL_VIEW_KINDS`, загрузка skeleton/atlas из
     папки скина), отдельным ленивым чанком. Готовых Spine-ассетов у заказчика
     пока нет: делаем контракт, загрузку, фабрику и тесты, без демо-ассета.
     Spine Runtimes требуют лицензии Spine Editor у того, кто их использует, -
     пометка в README.
   - **Размер бандла**: бюджет в CI (скрипт `bundle:check` по `dist/`),
     Pixi подключается точечными импортами там, где v8 это позволяет,
     Spine и рантайм партии - ленивые чанки, баррель `@/widgets/game` без Pixi
     (тест-сторож как `barrelPhaserFree.test.ts`, только для `pixi.js`).

## Эталон

Эталоном поведения при переносе был Phaser-шаблон `match3-template` (его
`src/`, `docs/`, `CLAUDE.md`); пока папка лежала в его репозитории, код
эталона читался, но не импортировался и не правился. Ссылки «эталон» в
журнале и комментариях кода - на него; в этом репозитории его нет.

## Что переносится копией, что пишется заново

**Копией** (с правками путей, ключей хранилища и текстов «Phaser» → «рантайм»):

- `src/app`, `src/pages` (включая `minimalHost`), `src/features`,
  `src/shared`, `src/entities` (движок `BoardEngine`, формат уровней, паки,
  витрина, бот, скин), `src/widgets/modals`, `src/widgets/levelConfigEditor`,
  `src/assets`, `public/`, `config/`, `scripts/`, `index.html`, тесты всех
  этих слоёв;
- из `src/widgets/game` - всё, что не трогает Phaser: `ui/*` (обёртки,
  баннер, подсказки), `model/*` (кроме типа `Phaser.Game`), `store/*`,
  `texts.ts`, чистые `configs/*` (`GAME_CONFIG`, `timing`, `renderQuality`,
  `sceneInsets`, `designSize`, `sceneDepths`, `levelConfig`), чистые `lib/*`
  (`boardFit`, `boardGeometry`, `boardTempo`, `tapSelection`, `swapDragOffset`,
  `pendingBoardInput`, `perfGovernor`, `comboPhrases`, `comboAnchor`,
  `scoreMeter`, `fallPath`, `mergeBoardTiming`, `canShowIdleHint`,
  `measureSceneInsets`, `resolveInsetStyle`, `setRuntimeLevelConfig`,
  `applyRenderQuality`, `warmGameAssets`, `warmPartyAssets`),
  `audio/soundRecipes`, `audio/soundPreference`.

**Заново под Pixi** (`src/widgets/game`): запуск и жизненный цикл, загрузка
ассетов и процедурных текстур, слои, ресайз/DPR/отступы, пауза, ввод,
потеря контекста, твины и задержки, шина событий рантайма, оркестратор хода,
проигрыватель шагов и анимации шагов, сущности и виды клеток, HUD, эффекты,
частицы, перф-монитор, звук на своём `AudioContext`. Внешний контракт
виджета не меняется: `GameScreenLazy`, `IGameScreenProps`, `TBoardEvent`,
`IGameRuntime` (без `game: Phaser.Game`), баррель `@/widgets/game`.

Архитектуру рантайма строим сразу под Pixi, без обходов Phaser: нет
глобала `GAMECORE` в инициализаторах полей (ядро передаётся явно), нет
сцен (`Application` + слои-контейнеры), нет обратного `zoom` (`resolution` +
`autoDensity`). Сохраняем то, что в Phaser-шаблоне - решение, а не обход:
движок отдаёт шаги, рантайм только проигрывает; реестр анимаций шагов с
`stepAnimationOverrides.ts`; вид клетки по `board.view` скина и
`CELL_VIEW_KINDS`; вид на доске по `BOARD_VIEWS`; цели засчитываются
`listGoalEvents`, а не по уничтожению спрайтов; ровно один живой рантайм.

## Соответствие Phaser → Pixi

| Phaser                                                   | Pixi v8 / GSAP                                                                                  | Заметки                                                                                                                          |
| -------------------------------------------------------- | ----------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| `Phaser.Game` + `PreloadScene`/`MainScene`               | `Application` (`await app.init`) + `await Assets.load` в `bootGameRuntime`                      | сцен нет                                                                                                                         |
| `LayerManager` (`Background`, `GameBoard`, `TopMenu`, …) | контейнеры под `app.stage`                                                                      | порядок слоёв = порядок `addChild`                                                                                               |
| `setDepth`, `sceneDepths`                                | `zIndex` + `sortableChildren`                                                                   | числа `sceneDepths` те же                                                                                                        |
| `setOrigin`                                              | `anchor` у `Sprite`/`Text`, `pivot` у `Container`                                               |                                                                                                                                  |
| `scene.tweens.add`, ease `'Back.easeOut'`                | `gsap.to/fromTo`, ease `'back.out'`                                                             | таблица ease-имён; формулы Пеннера те же. Все твины и задержки - в корневом `timeline` рантайма: его пауза и `timeScale` - общие |
| `tweens/time.timeScale` (финал)                          | `timeScale` корневого `timeline`                                                                |                                                                                                                                  |
| `scene.pause()`                                          | `app.ticker.stop()` + `timeline.pause()` + пауза звука                                          |                                                                                                                                  |
| `scene.events` для своих событий                         | типизированная шина рантайма (`EventEmitter` из `pixi.js`)                                      |                                                                                                                                  |
| `Text` с CSS-стилем                                      | `Text` + `TextStyle`, `resolution` от `getTextResolution()`                                     | шрифт - `SKIN.fonts.game`; дождаться `document.fonts` до первого текста                                                          |
| `Graphics`                                               | `Graphics` v8 (`rect().fill()`, `circle().stroke()`)                                            |                                                                                                                                  |
| частицы (`add.particles`)                                | `ParticleContainer` + `Particle` v8 и свой эмиттер на `Ticker`                                  |                                                                                                                                  |
| `cameras.main.shake`                                     | смещение корневого контейнера твином                                                            | параметры `TCameraPunch` те же                                                                                                   |
| покадровые клипы (`frameHeight`)                         | нарезка `Texture` с `frame: Rectangle` + `AnimatedSprite`                                       |                                                                                                                                  |
| `textures.createCanvas` (процедурный арт)                | `Texture.from(canvas)`                                                                          | `entities/skin/lib/canvasArt` без правок                                                                                         |
| загрузчик `HTMLImageElement` + `crossOrigin`             | `Assets` с `loadTextures.config` без воркеров и `createImageBitmap`, `crossOrigin: 'anonymous'` | иначе прогрев `warmGameAssets` и загрузчик не делят кэш (CDN `VITE_CDN_BASE_URL`) - проверить вкладкой Network                   |
| `ScaleManager` `NONE` + обратный `zoom`                  | `resolution: getRenderDpr()`, `autoDensity: true`, `renderer.resize(cssW, cssH)`                |                                                                                                                                  |
| `Zone`, `pointerupoutside`, `input.on('pointermove')`    | `hitArea` + `eventMode: 'static'`, `pointerupoutside`, `globalpointermove`                      | семантика из `docs/game-flow.md` эталона («Ввод», «Очередь ввода») - тестами на автомат ввода                                    |
| `input.enabled = false` + `Pointer.reset()`              | `stage.eventMode = 'none'` + сброс незавершённого жеста                                         | правило `ExitButton` по `pointerup` и `inert` проверить заново                                                                   |
| `game.registry`, отложенный `game.destroy()`             | ядро держит `Application`; `app.destroy()` синхронный                                           | StrictMode: двойной маунт не должен поднимать два рантайма                                                                       |
| событие `render` первого кадра                           | `app.ticker.addOnce` после первого рендера                                                      | снимает `isGameLoaded`                                                                                                           |
| WebGL `LOSE_WEBGL`/`RESTORE_WEBGL`                       | DOM-события канваса `webglcontextlost/restored`; для WebGPU - `device.lost`                     | отказ `context-lost` по тому же таймауту                                                                                         |
| `WebAudioSoundManager.context`                           | свой `AudioContext`, разблокировка по первому жесту                                             | рецепты звука те же                                                                                                              |
| `Phaser.Math.Clamp/Distance/RadToDeg/Linear`             | `shared/lib/math`                                                                               |                                                                                                                                  |
| `manualChunks` `phaser`                                  | чанки `pixi`, `gsap`, `spine`                                                                   |                                                                                                                                  |

## Фазы

Каждую фазу делает отдельный агент. В конце фазы агент:

- прогоняет из `match3-pixi/`: `npm run type-check`, `npm run lint`,
  `npm run format:check`, `npm run test:ci`, `npm run build`
  (с фазы 0 - зелёные; падения - чинить или явно записать в журнал);
- проверяет то, что видно глазами, в dev-сервере (`npm run dev` из
  `match3-pixi/`, превью-браузер) и сравнивает с Phaser-версией (корневой
  `npm run dev`) на той же партии `?level=N&seed=S`;
- дописывает запись в [журнал](#журнал-фаз): что сделано, что проверено, что
  осталось, отклонения от плана;
- **не коммитит**, не создаёт веток, не правит код Phaser-шаблона (эталона).

### Фаза 0. Каркас и перенос слоёв без рендера

- Конфиги проекта из корня, адаптированные к папке (`name: "match3-pixi"`,
  без `phaser`, с `pixi.js`, `gsap`, `@esotericsoftware/spine-pixi-v8`),
  `npm install` внутри папки - свой `package-lock.json`.
- Копия слоёв из раздела «Копией», ключи хранилища по инварианту 4.
- `widgets/game`: копия чистых частей; рантайм - заглушка, которая честно
  отдаёт `onError` (партия не играется, остальное приложение работает).
- `README.md`, `CLAUDE.md`, `AGENTS.md`, `docs/` - копия с правкой имени,
  ключей и пометкой, что рантайм на Pixi в работе (ссылка на этот план).
- Корень репозитория: исключить `match3-pixi/` из корневых ESLint
  (`ignores`), Vitest, Prettier (`.prettierignore`), lint-staged и
  `graphify` (если индексирует), чтобы корневые проверки не лезли в папку.
  Husky внутри папки - скрипт `prepare` безопасен, пока папка не корень git.

Готово, когда: приложение в dev открывается, главная, карта, витрина,
редактор работают, тесты перенесённых слоёв (включая `test:slow` с ботом)
зелёные, проверка независимости (копия в пустой каталог) проходит.

### Фаза 1. Ядро Pixi-рантайма

Запуск (`bootGameRuntime`, `Application` с WebGPU → WebGL), загрузка файлов
и процедурных текстур, отказ `assets`, слои, ресайз/DPR/`insets`/
`sceneLayout`, пауза, включение ввода, потеря контекста, `destroy`, первый
кадр → `isGameLoaded`, один живой рантайм; `motion` (GSAP: `tween`
промисом с защитой от зависания, `delay`, `timeScale`, пауза), шина событий,
`SoundEngine` на своём `AudioContext`, `PerfMonitor` и понижение качества.
Тесты на чистые части (ease-таблица, `motion` с фейковым тикером, шина).

Готово, когда: партия монтируется, фон и пустая сетка рисуются в нужной
области на десктопе и мобильном вьюпорте, пауза/ресайз/размонтирование без
утечек, `?renderer=webgl|webgpu` переключает рендерер.

### Фаза 2. Доска, ввод, ход

Сущности клеток и слои клетки, виды клеток (`sprite`, `frames`) по
`CELL_VIEW_KINDS`, `BOARD_VIEWS`, `CellMover`, проигрыватель шагов и реестр
анимаций шагов с `stepAnimationOverrides.ts`, ввод (свайп, два тапа,
коммит на отпускании, отпускание за канвасом, буфер под каскадом),
маркер выбора, выбор цели бустера, оркестратор хода (`GameLogic`), цели по
`listGoalEvents`, подсказка простоя и тупика, near-miss
(`onOutOfMoves`), финальный бонус, исход в хост, события `onBoardEvent`.
Эффекты на этой фазе - заглушки `IBoardFx` (без частиц).

Готово, когда: любой уровень пака и витрины играется до исхода, при том же
`?seed` события `onBoardEvent` совпадают с Phaser-версией, редактор
показывает превью.

### Фаза 3. HUD

Панель целей с интро, счётчик ходов, шкала очков со звёздами, кнопки
бустеров, подпись уровня, выход, звук, фон доски, «дыхание» простоя,
акценты каскада, хайп-фраза (DOM уже есть). Внешний вид и раскладка - как в
Phaser-версии.

### Фаза 4. Эффекты

`IBoardFx` на Pixi: частицы, вспышки, затемнение, тряска, линии ракет,
бомба, радуга, пропеллер, комбинации, эффекты бустеров, полёт к цели,
конец партии. Сверка с Phaser-версией по каждому виду шага (витрина - по
уровню на механику).

### Фаза 5. Spine, WebGPU, бюджет бандла

Вид клетки `spine` (контракт скина, загрузка, фабрика, ленивый чанк,
тесты на контракт без ассета), проверка всех эффектов на WebGPU и WebGL,
`bundle:check` с бюджетом в CI, замер чанков против Phaser-версии
(Phaser - 1,2 МБ / 330 КБ gzip).

### Фаза 6. Паритет, CI, документация

Прогон всех уровней витрины и выборки пака рядом с Phaser-версией,
устройства (мобильный вьюпорт, DPR 3), `.gitlab-ci.yml` (тесты, сборка,
бюджет), Husky, финальная документация: `CLAUDE.md`, `AGENTS.md`, `README`,
`docs/*` описывают Pixi-рантайм (жизненный цикл, ввод, анимации, твины,
загрузка, WebGPU, Spine, бандл) и не упоминают Phaser как активный слой.
Повторная проверка независимости (копия в пустой каталог).
