# CODEMAP

Плотный индекс для быстрого входа в текущий Vite-шаблон с рантаймом партии на
Pixi v8 + GSAP 3 (порт Phaser-шаблона; история - [PLAN.md](./PLAN.md)).

## Сначала Граф

Если граф собран (`graphify-out/graph.json`, команда `graphify update .`),
перед использованием этого индекса для codebase-задачи сначала спроси graphify:

- широкий вопрос: `graphify query "<что нужно понять>" --budget 1200`;
- связь между сущностями: `graphify path "<A>" "<B>"`;
- один узел или модуль: `graphify explain "<concept>"`.

После этого открывай только файлы/строки из ответа графа (`src=... loc=...`). К таблицам ниже переходи как к fallback-индексу, если графа нет или он не дал достаточно точный срез.
